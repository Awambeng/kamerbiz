# Simple glossary

| Word               | Meaning                                                                             |
| ------------------ | ----------------------------------------------------------------------------------- |
| Business owner     | The person who runs a business                                                      |
| Storefront         | The public page where customers view products                                       |
| Dashboard          | The private area where a business manages its store                                 |
| Order              | A customer's request to buy products                                                |
| Payment evidence   | Information or a screenshot sent by a customer to help the business check a payment |
| Fulfilment         | Preparing and handing an order to the customer                                      |
| Pickup             | The customer collects the order                                                     |
| Tenant             | One business account inside a platform shared by many businesses                    |
| MVP                | The first small version of a product that real users can test                       |
| Pilot              | A small real-world test before a wider launch                                       |
| API                | A way for two software systems to exchange information                              |
| Backend            | The part of the system that handles data and business rules                         |
| Frontend           | The part of the system that users see and interact with                             |
| Database           | The organised place where the system stores information                             |
| Hosting            | The service that runs the application online                                        |
| Source attribution | Recording where a customer came from, such as Instagram or WhatsApp                 |
| Audit record       | A record showing who made an important change and when                              |
